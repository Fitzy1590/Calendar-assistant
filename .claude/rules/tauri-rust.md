# Tauri / Rust rules (Windows + Android)

## Building and checking
- This sandbox cannot build the app (no WebView2/webkit). Do not try `cargo build` or `tauri build` here.
- Pure logic goes in a `*_core.rs` module with no Tauri imports (`imap_core.rs`, `self_update_core.rs`). Test it by
  copying the file into a scratch crate and running `cargo test`.
- Format: `rustfmt --edition 2021 src-tauri/src/*.rs` (check with `--check`).
- The real proof is a green GitHub `build` run: `check`, `windows` and `android` jobs.

## Platform split
- Windows-only code is behind `#[cfg(windows)]` / `#[cfg(desktop)]`; Android gets a stub with the same command names
  (see `imap_stub.rs`), so the TypeScript side never branches on what exists.
- Every new `#[tauri::command]` is registered in `lib.rs` and, if it needs a plugin permission, added to
  `capabilities/default.json` (all platforms) or `capabilities/desktop.json` (desktop only).
- TypeScript calls commands through a module in `src/lib/` guarded by `isTauri` from `lib/platform.ts`, with a browser
  fallback. Pages never call `invoke` directly.

## Do not touch
- `src-tauri/gen/` is generated by `npm run android:init` and is git-ignored. Android manifest changes go through
  `scripts/android-permissions.mjs`.
- `tauri.conf.json` `identifier` (`com.fitzy.calendarassistant`) and the updater public key: changing either breaks
  updates for every installed copy.
- `version` in `tauri.conf.json`, `Cargo.toml` and `package.json` is stamped by CI (`scripts/set-version.mjs`); leave
  it at `0.1.0` in the repo.
- No secrets in Rust source or logs. Tokens go through `secure_store.rs` (Windows Credential Manager).

## Safety
- `self_update.rs` only trusts installers from this repo's GitHub releases with a published SHA-256. Do not loosen
  the URL or checksum checks.
- Crash and auto-fix code (`crash.rs`, `webview_fix.rs`) must never delete user data or change OS settings silently.
