## Install

**Windows** — download `Calendar Assistant_…_x64-setup.exe` (or the `.msi`) below and run it.
The installer isn't code-signed yet, so Windows may show *"Windows protected your PC"*: choose **More info → Run anyway**.

**Android** — download the `.apk` below on your phone and open it. Android will ask you to allow installing apps from your browser or files app the first time.
If the file is named `…-test-signed.apk`, it was built before a release signing key was set up: it works, but uninstall it before installing a properly signed version later.

**Sync between Windows and Android** needs the small sync server from this repository running somewhere both devices can reach (see the README, "Linking the phone"). Invite Accept links also need it on a public HTTPS address.
